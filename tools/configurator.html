Connect your macropad

This page talks to the Detent firmware directly over USB. No drivers, nothing to install. Use Chrome or Edge, then click Connect.

Is the firmware installed? If the macropad still runs its stock firmware, run flash.bat first. A macropad in compatibility wheel mode (shows up as a plain Xbox 360 pad) can't be configured: plug it in while holding key 3 to start in keyboard mode.

The Fn layer is active while a key set to “Fn layer” is held.
