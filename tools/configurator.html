    Timing

    Hold time

    How long a key must be held for its long-press action.

    Tap length

    How long a key press lasts when the pad taps a key for you (knob clicks, released combos). Raise it if a program misses taps.

    Switcher hold after turning

    When a knob turn keeps a modifier held (like Alt for Alt+Tab), it is let go this long after the last click.

    Debounce

    Raise it if one press is sometimes counted twice.

    Profiles and startup

    Profiles

    How many profiles you use. The pad's memory is small: every profile you don't use leaves 22 more bytes for combos and multi-step actions.

    Profile after plugging in

    The pad starts in this profile.

    Backup and reset

    This replaces every profile, combo and option.

    The file works with the command-line tool too (wildpad.py import).

    Firmware

    A pad that still runs its factory firmware: install Wildpad step by step.

    The pad switches to its update mode by itself; the browser asks once to use Wildpad: pick it. No driver is needed. If the pad doesn't answer, plug it in while holding key 1 and press Update firmware: that starts the chip's own bootloader (USB Module), which on Windows needs the WinUSB driver once: run Zadig while it's connected, choose USB Module, install WinUSB. Without the browser: flash.bat from the Wildpad download.
